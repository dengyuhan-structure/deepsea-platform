# 公开数据集说明

本项目**没有自己拍摄的深远海养殖视频**。鱼类板块的"摄食强度/鱼群行为"相关能力，
依据公开数据集建立。本文件说明用了什么、怎么用、以及**哪些说法不能讲**。

---

## 一、TFBID — 罗非鱼摄食行为图像数据集

### 出处（可查证）

| 项 | 内容 |
|---|---|
| **全称** | TFBID — **T**ilapia **F**eeding **B**ehavior **I**mage **D**ataset |
| **作者** | Hassan, Shahbaz |
| **发布** | 2025-10-11（Zenodo） |
| **DOI** | **10.5281/zenodo.17355839** |
| **链接** | https://zenodo.org/records/17355839 |
| **许可** | **CC-BY-4.0**（可自由使用，需署名） |
| **物种** | 尼罗罗非鱼 *Oreochromis niloticus* |
| **采集地** | **中国广州 · 仲恺农业工程学院南沙实验罗非鱼场** |
| **养殖系统** | 循环水养殖（**RAS**），8 个圆池，直径 2.7 m、深 0.8 m |
| **规模** | **4000 张水下 RGB 图像**，按摄食强度分 4 级，每级 1000 张 |
| **分辨率** | 1839 × 998 |

### 为什么用它

1. **有明确出处、有 DOI、许可是 CC-BY-4.0** —— 答辩时能当场打开
2. **就是中国的水下养殖图像**，不是随便找的国外数据集
3. **已按摄食强度分级标注** —— 正好对上鱼类板块要的"摄食强度"字段
4. **场景是 RAS 圆池** —— 与网箱养殖的水下成像条件接近（浑浊水体、人工光源、鱼群聚集）

## 二、仓库里放的是什么（**不是整个数据集**）

```
data/公开数据集/TFBID-样例/
├── none/     12 张   无摄食
├── weak/     12 张   弱摄食
├── medium/   12 张   中等摄食
└── strong/   12 张   强摄食
```

**合计 48 张，约 4.6 MB。**

### ⚠️ 为什么只放样例，不放全部 4000 张

| 原因 | 说明 |
|---|---|
| **GitHub 限制** | 完整数据集是 **376 MB**；GitHub 单文件上限 100 MB，仓库也不该塞几百兆 |
| **本项目自己的规矩** | 《GitHub上传教程》第七节写明：**公开数据集写下载地址，不传本体** |
| **抽样方式** | 每类 1000 张里**等间隔抽 12 张**（不是只取前 12 张），覆盖整个采集过程 |

### 怎么拿完整数据集

```
https://zenodo.org/records/17355839
├── fishdata.zip   376.1 MB   ← 4000 张图像（本目录的样例就是从它抽的）
└── TFBID.rar        5.3 MB   ← 训练/评估代码与文档（不含图像）
```

> **实测下载速度约 1 MB/s，约 6~8 分钟。** 本项目用 `Start-BitsTransfer`（可断点续传）下载成功。

## 三、四个等级分别是什么样（**已人工核对**）

| 目录 | 中文 | 图像特征 |
|---|---|---|
| `none` | 无摄食 | 鱼在中层/底层**平静游动**，不集群，口不张 |
| `weak` | 弱摄食 | 开始上浮，分散 |
| `medium` | 中等摄食 | 明显上浮、开始聚集 |
| `strong` | **强摄食** | 鱼群**密集上浮到水面、张着嘴抢食** |

> 抽查确认：图像是**真实水下照片**，右下角烙有「**水下3号鱼池**」水印，
> 与元数据（广州仲恺、2.7 m 圆池 RAS）**完全对得上**。

## 四、🔴 使用时**不能这么讲**（答辩风险点）

### 1. 物种不是同一个

**TFBID 是罗非鱼（淡水/咸淡水），而平台主养种配的是大黄鱼（海水）。**

**能说**：*"我们用 TFBID 公开数据集验证了「图像 → 摄食强度分级」的处理流程。"*
**不能说**：*"我们的系统能识别大黄鱼的摄食行为。"* —— 我们没有大黄鱼的水下图像，也没训练过。

### 2. 我们没有训练深度学习模型

鱼类板块的《板块细化文档》已明确列入"**明确不做**"：*不训练深度学习模型、不做图像直接反演体重*。

**能说**：*"接口与数据格式已按标准预留，接入真实视觉识别结果即可。"*
**不能说**：*"我们的 AI 识别准确率是 xx%。"* —— 没有训练、没有真值，报了精度就答不出"跟什么比"。

### 3. 平台上的鱼类数据目前仍是仿真值

平台里鱼群数量、体长体重等是程序按生长模型生成的，**来源标签标的是"仿真数据"**，
**不是从这些图像实时识别出来的**。这两件事不要混着讲。

## 五、DeepFish（备选，本项目**未采用**）

王浩然文档中提到的另一个数据集：**DeepFish**（James Cook University，约 4 万帧 1920×1080）。

**本项目未下载、未使用。** 理由：TFBID 已满足"有分级标注 + 中国场景 + 许可清晰"三条，
再引入一个数据集只会增加讲解负担而不增加证据强度。
